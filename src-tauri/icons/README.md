# 应用图标目录（占位说明）

本目录当前**没有图标文件**，这是已知的、有意的缺口：图标由「品牌/Logo/图标」任务产出（DG 9.2 进度表最后一行，可与 M0 并行）。

## 当前影响（不要当成 bug 反复排查）

- `pnpm tauri build` / `cargo tauri build` 会因为找不到 `tauri.conf.json` 中 `bundle.icon` 列出的文件而**失败**。
- `pnpm tauri dev` 不受影响（dev 不打包图标资源）。

## 需要放置的文件（与 `tauri.conf.json` 的 `bundle.icon` 一一对应）

| 文件 | 用途 |
|---|---|
| `32x32.png` | 小尺寸位图 |
| `128x128.png` | 常规位图 |
| `128x128@2x.png` | 高 DPI 位图（实际 256x256） |
| `icon.ico` | **Windows 必需**：exe 图标、安装器图标、文件关联图标；需内含 16/32/48/64/256 多尺寸 |

## 生成方式

品牌任务产出一张 ≥1024x1024 的方形 PNG 源图（DG 5.8：圆角方形底 + `M↓` 符号，品牌色 `#4C8DF6`）后，在仓库根目录执行：

```
pnpm tauri icon path/to/source-1024.png
```

该命令会把全套图标写入本目录（含 macOS/Linux 尺寸，本项目仅用到上表四个，多余文件可保留不影响 Windows 打包）。

## 注意

- 文件关联的图标同样取自 `icon.ico`（bundler 自动关联），因此 `.md` 文件在资源管理器中的显示效果取决于 ico 的 16x16 与 32x32 图层质量，务必单独校对这两档不糊。
- 图标更换后需重新执行一次完整 `pnpm tauri build` 并核对：exe 图标、安装器图标、关联文件图标、任务栏图标四处。
